# PRD: 영단어 플래시카드 웹앱 — 2단계 (진척도·필터·단어 관리 고도화)

## 0. 1단계 대비 변경점 (요약)

이 문서는 **자기완결 문서**다. 2단계 시점의 전체 스펙(1단계에서 유지되는 내용 + 2단계 신규 내용)을 모두 포함하므로, 이 문서 하나만 보면 현재 앱의 전체 요구사항을 알 수 있다. 1단계와 비교한 변경점만 빠르게 보고 싶다면 아래 목록만 보면 된다.

- **(신규) 진척도 표시**: 학습 화면 상단에 "완료 n / 전체 m" 텍스트와 진행 막대 추가.
- **(신규) 학습 범위 필터**: "전체 / 미완료만" 전환 컨트롤 추가. `AppState.filter`가 1단계에서는 정의만 되고 `"all"`로 고정되어 있었는데, 2단계부터 실제로 동작하며 신규 실행 시 기본값이 `"unmemorized"`(미완료만)로 바뀐다. 1단계에서 이미 저장된 데이터의 `filter` 값은 그대로 유지된다(강제 마이그레이션 없음).
- **(신규) 모든 단어 완료 화면**: "미완료만" 모드에서 남은 단어가 없을 때 축하 화면 표시.
- **(신규) 단어 수정·삭제**: 단어 관리 화면에서 인라인 수정과 삭제(확인 대화상자) 지원. 목록 정렬을 "최신 추가 순"으로 변경하고 전체 단어 수를 표시.
- **(신규) 중복 확인**: 영단어 추가 시 대소문자·공백을 무시한 중복 검사와 확인 대화상자 추가.
- **(신규) 저장 용량 초과 처리**: `localStorage` 저장 중 `QuotaExceededError` 발생 시 전용 안내 메시지 표시(기존 "저장 불가" 배너와 구분).
- 그 외 카드 뒤집기, 다음 카드, 암기 완료 토글, 저장 데이터 손상 복구, 반응형·접근성 요구사항은 1단계와 동일하게 유지된다.

## 1. 개요

브라우저에서 바로 쓰는 1인용 영단어 플래시카드 웹앱의 2단계 요구사항 문서다. 1단계(MVP)에서 만든 카드 학습·단어 추가·저장 기능 위에, 학습 진척도를 확인하고 학습 범위를 좁히고(미완료 단어만 보기) 단어를 관리(수정·삭제)하는 기능을 더한다.

- **상태**: 완료 (구현·검증 완료)
- **구현 위치**: `index.html`, `style.css`, `app.js` (프로젝트 루트)
- **범위**: 전체 3단계 중 2단계. 1단계 PRD: [`stage1-mvp.md`](./stage1-mvp.md)

## 2. 목표

- 지금까지 얼마나 외웠는지 한눈에 보여준다(진척도 숫자 + 막대).
- 이미 외운 단어는 복습 순환에서 빠지게 해서, 아직 못 외운 단어에 집중할 수 있게 한다.
- 모든 단어를 다 외웠을 때 명확한 성취감을 주는 화면을 보여준다.
- 잘못 입력했거나 더 이상 필요 없는 단어를 직접 고치고 지울 수 있게 한다.
- 같은 단어를 실수로 중복 등록하지 않도록 돕는다.
- 저장 공간이 부족한 극단적인 상황에서도 앱이 깨지지 않고 현재 화면 상태를 유지한다.
- 1단계의 모든 기능과 저장된 데이터(`localStorage "vocabCards.v1"`)는 그대로 보존한다.

## 3. 목표가 아닌 것 (Out of scope)

- 서버 연동, 계정/로그인, 기기 간 동기화
- 발음, 예문, 이미지 등 단어 부가 정보
- 통계(일별 학습량 등), 복습 주기(SRS) 등 학습 알고리즘
- 단어 폴더/카테고리 분류, 검색, 정렬 기준 변경(현재는 "최신 추가 순" 고정)
- 다국어 UI (한국어 고정)
- 여러 단어 한 번에 선택해 일괄 삭제/이동하는 기능

이 항목들은 3단계 또는 그 이후 범위에서 다룬다.

## 4. 사용자 및 사용 시나리오

- **대상 사용자**: 영단어를 혼자 암기하려는 1인 사용자(한국어 사용자), 별도 설치 없이 바로 쓰고 싶은 사람.
- **핵심 시나리오**:
  1. 앱을 열면 기본적으로 "미완료만" 모드로 학습 화면이 보이고, 상단에 전체 진척도가 보인다.
  2. 카드를 눌러 뜻을 확인하고, 외웠으면 "암기 완료"를 누른다. 카드는 바로 사라지지 않고 그대로 보이다가, "다음"을 누르는 순간 복습 순환에서 빠진다.
  3. 모든 단어를 다 외우면 축하 화면이 뜨고, "전체 다시 보기"로 처음부터 복습을 이어갈 수 있다.
  4. 단어 관리 화면에서 오타를 고치거나(수정), 더 이상 필요 없는 단어를 지운다(삭제).
  5. 이미 등록한 단어를 대소문자만 바꿔 다시 추가하려 하면 중복 확인을 받는다.
  6. 탭을 닫았다가 다시 열어도 단어 목록·완료 상태·필터 선택이 그대로 남아있다.

## 5. 기술 조건

- 순수 HTML/CSS/JavaScript, 프레임워크·빌드 도구 없음. 파일은 `index.html`, `style.css`, `app.js` 3개로 구성(1단계와 동일, 신규 파일 추가 없음).
- 브라우저에서 파일을 직접 열거나(`file://`), GitHub Pages 같은 정적 호스팅으로 실행 가능해야 함.
- 외부 라이브러리, 분석 스크립트, 외부 네트워크 요청 없음(완전 오프라인 동작).
- UI 문구는 모두 한국어.
- 기존 저장 데이터(`vocabCards.v1`)의 구조를 깨지 않고 확장한다. 1단계에서 저장된 데이터도 별도 변환 없이 그대로 읽을 수 있어야 한다.

## 6. 화면 구성

화면은 2개이며, 전환은 섹션 표시/숨김(`hidden` 속성)으로 처리한다. 앱 시작 시 항상 학습 화면이 먼저 보인다.

### 6.1 학습 화면
- 헤더: 앱 이름("영단어 카드"), "단어 관리" 버튼
- **(신규) 진척도 영역**: "완료 n / 전체 m" 텍스트, 진행 막대, "전체 / 미완료만" 필터 전환 컨트롤. 단어가 0개면 이 영역 전체를 숨긴다.
- 카드 영역 — 아래 세 가지 상태 중 하나를 보여준다.
  - 단어가 1개도 없을 때: "외울 단어를 추가해 보세요" 안내 + "단어 추가" 버튼
  - **(신규)** 단어는 있지만 현재 필터("미완료만") 기준으로 남은 카드가 없을 때: "모든 단어를 외웠어요!" 축하 화면 + "전체 다시 보기" 버튼
  - 그 외: 플래시카드 + 위치 표시("3 / 20", 현재 필터의 학습 대상 목록 기준)
- 하단 고정 컨트롤: "암기 완료" 토글 버튼, "다음" 버튼(가장 크게). 위 두 가지 빈 상태에서는 비활성화된다.

### 6.2 단어 관리 화면
- "학습으로 돌아가기" 버튼
- 영단어·뜻 입력 폼 + "추가" 버튼
- **(신규)** 전체 단어 수 표시("전체 12개")
- 전체 단어 목록(영단어, 뜻, 완료 여부), **최신 추가 순 정렬**
- **(신규)** 목록 각 행에 "수정"(인라인 편집 폼으로 전환), "삭제"(확인 대화상자 후 삭제) 버튼

화면 전환 시 상태는 보존된다. 즉, 단어 관리 화면에 다녀와도 학습 화면은 보고 있던 카드를 그대로 유지한다.

## 7. 기능 요구사항

### F1. 카드 표시·뒤집기 (1단계 유지)
- 앞면에는 영단어만 크게, 뒷면에는 뜻(영단어는 작게 함께 표시)을 보여준다.
- 카드를 클릭·탭하면 앞↔뒤가 전환되며, 0.3~0.5초의 3D 회전 애니메이션이 재생된다. `prefers-reduced-motion` 환경에서는 즉시 전환된다.
- 다음 카드로 넘어가면 항상 앞면부터 다시 보여준다.
- 암기 완료된 카드에는 "완료" 배지를 표시한다.
- 애니메이션 진행 중의 연속 클릭은 무시한다.
- 긴 단어·뜻은 글자 크기를 줄이고 줄바꿈하여 카드 밖으로 넘치지 않게 한다.
- 카드는 `button` 요소로 구현하여 키보드 Enter/Space로도 뒤집을 수 있다.

### F2. 다음 카드 (1단계 유지 + 필터 연동)
- "다음" 버튼을 누르면 **현재 필터의 학습 대상 목록** 기준으로 다음 단어로 이동한다.
- 마지막 카드에서 "다음"을 누르면 목록의 첫 카드로 순환하고, "한 바퀴를 다 봤어요" 안내를 짧게 1회 보여준다(목록에 단어가 2개 이상일 때만).
- 목록에 단어가 1개뿐이면 같은 카드를 유지하되 앞면으로 되돌린다.

### F3. 암기 완료 토글 (1단계 유지 + "즉시 사라지지 않음" 보강)
- 카드 아래 "암기 완료" 버튼을 누르면 완료 처리되고, 다시 누르면 해제된다. 변경 사항은 즉시 저장되고, 카드의 "완료" 배지도 즉시 바뀐다.
- **(신규)** "미완료만" 필터에서 현재 보고 있는 카드를 암기 완료로 체크해도, 그 카드는 화면과 위치 표시("n / m")에서 즉시 사라지지 않는다. "다음"을 눌러야 비로소 그 카드가 학습 순환에서 빠진다. (상단 진척도 숫자는 필터와 무관하게 즉시 갱신된다 — F6 참고.)

### F4. 단어 추가·목록 (1단계 유지 + 중복 확인)
- 영단어·뜻 두 칸 모두 필수이며, 입력값의 앞뒤 공백은 제거한다.
- 하나라도 비어 있으면 추가 버튼이 비활성화되거나 "영단어와 뜻을 모두 입력해 주세요" 안내를 보여준다.
- 영단어 최대 100자, 뜻 최대 200자로 제한한다.
- Enter 키로도 추가할 수 있고, 추가 후에는 영단어 입력란에 자동으로 포커스가 이동한다.
- 추가한 단어는 즉시 목록과(현재 필터에 맞는 경우) 카드 순환에 포함된다.
- 저장된 데이터가 없는 첫 실행 시, 중급 수준 영단어 10개(뜻 포함)를 샘플로 넣어 바로 체험할 수 있게 한다.
- **(신규, F10과 연결)** 같은 영단어(대소문자·앞뒤 공백 무시)가 이미 목록에 있으면, 추가하기 전에 "이미 있는 단어예요. 그래도 추가할까요?" 확인을 거친다. 취소하면 추가하지 않고 입력값을 그대로 유지한다.

### F5. 저장·복원 (localStorage) (1단계 유지)
- 키 `vocabCards.v1` 하나에 전체 상태를 JSON으로 저장한다.
- 단어 추가·수정·삭제, 완료 상태 변경, 필터 변경, 현재 카드 이동 등 상태가 바뀔 때마다 즉시 저장한다.
- 페이지 로드 시 단어 목록, 완료 상태, 필터, 마지막으로 보던 카드를 복원한다(복원 직후 카드는 항상 앞면).
- 복원 시 현재 필터 기준으로 학습 대상 목록을 다시 계산하므로, 저장 당시엔 "미완료만" 모드에서 막 완료 처리되어 화면에 남아 있던(F3) 카드가 있었다면, 새로고침 후에는 그 카드 대신 해당 필터의 첫 카드가 보일 수 있다. 이는 의도된 동작이다.

### F6. 진척도 표시 (신규)
- 학습 화면 상단에 "완료 n / 전체 m" 텍스트와 진행 막대를 표시한다. `n`은 암기 완료된 단어 수, `m`은 **필터와 무관하게** 전체 단어 수다.
- 암기 완료 체크/해제 즉시 숫자와 막대가 갱신된다.
- 단어가 0개면 진척도 영역 자체를 숨긴다.

### F7. 학습 범위 필터 (신규)
- 진척도 영역에 "전체 / 미완료만" 전환 컨트롤을 둔다.
- 신규 실행(저장된 데이터 없음) 시 기본값은 "미완료만"이다. 선택한 필터는 `AppState.filter`에 저장되어 새로고침 후에도 유지된다.
- "미완료만"이면 암기 완료된 단어는 카드 순환(F2)과 위치 표시에서 제외된다.
- 위치 표시("3 / 20")는 항상 현재 필터의 학습 대상 목록 기준이다.
- 필터를 바꿨을 때 현재 보던 카드가 바뀐 필터의 대상 목록에 없으면, 그 목록의 첫 카드로 이동한다.

### F8. 모든 단어 완료 화면 (신규)
- "미완료만" 모드에서 학습 대상 목록이 비어 있으면(= 암기 완료되지 않은 단어가 하나도 없으면) 카드 대신 "모든 단어를 외웠어요!" 축하 화면을 보여준다.
- "전체 다시 보기" 버튼을 누르면 필터가 "전체"로 전환되어 모든 단어가 다시 순환 대상이 된다.
- 이 화면에서는 "다음"·"암기 완료" 버튼이 비활성화된다.

### F9. 단어 수정·삭제 (신규)
- 단어 관리 화면 목록의 각 행에 "수정", "삭제" 버튼을 둔다.
- **수정**: 버튼을 누르면 행이 인라인 편집 폼으로 바뀐다(영단어·뜻 입력 칸 + 저장/취소 버튼). 입력 검증 규칙(필수, 공백 제거, 영단어 100자/뜻 200자)은 추가(F4)와 동일하게 적용한다. 저장하면 해당 단어의 `updatedAt`이 갱신되고, 학습 화면에 그 단어가 보이고 있었다면 즉시 반영된다.
- **삭제**: 버튼을 누르면 확인 대화상자(`"{단어} 단어를 삭제할까요?"`)를 띄우고, 확인해야 실제로 삭제한다.
- 보던 카드가 삭제되면, 삭제되기 전 학습 대상 목록을 기준으로 그 다음 카드로 이동한다. 다음 카드가 없으면(그 목록에 남은 단어가 없으면) 빈 상태(단어 0개 안내 또는 모든 단어 완료 화면)로 자연스럽게 전환된다.
- 목록은 최신 추가 순으로 정렬하고, 상단에 전체 단어 수("전체 12개")를 표시한다.

### F10. 중복 확인 (신규)
- F4에 통합된 요구사항. 같은 영단어(대소문자·앞뒤 공백 무시)가 이미 있으면 "이미 있는 단어예요. 그래도 추가할까요?" 확인 후 사용자의 선택에 따라 추가 여부를 결정한다. 확인 대화상자는 브라우저 기본 `confirm()`을 사용한다.

### F11. 저장 용량 초과 처리 (신규)
- `localStorage` 저장 중 `QuotaExceededError`(또는 동급 에러)가 발생하면, 이미 반영된 화면 변경 사항(메모리상의 상태)은 그대로 유지한 채 "저장 공간이 부족해 저장하지 못했어요" 안내만 표시한다.
- 이 경우 `localStorage` 자체를 더 이상 사용하지 않는 "저장 불가 모드"(F5 예외 처리의 `storageAvailable = false`)로 전환하지 않는다. 즉, 용량 문제가 해소되면(예: 단어 삭제) 다음 저장 시도는 다시 정상적으로 성공할 수 있다. 이 점에서 `localStorage` 자체를 쓸 수 없는 경우(시크릿 모드 등, 9장 참고)와 구분된다.

## 8. 데이터 모델

```
Word
- id: string            (crypto.randomUUID, 미지원 시 타임스탬프+난수로 대체)
- term: string           (영단어)
- meaning: string         (뜻)
- memorized: boolean      (기본 false)
- createdAt: string        (ISO 8601)
- updatedAt: string        (ISO 8601, 추가/수정/완료 상태 변경 시 갱신)

AppState
- version: number         (현재 1, 1단계와 동일 — 구조 변경 없이 확장했으므로 올리지 않았다)
- words: Word[]           (추가된 순서 유지; 관리 화면 표시만 최신순으로 뒤집어서 보여준다)
- filter: "all" | "unmemorized"  (실제로 동작함. 신규 상태의 기본값은 "unmemorized")
- currentWordId: string | null   (인덱스가 아닌 ID로 현재 위치 저장)
```

데이터 모델 자체는 1단계와 동일하다(필드 추가 없음). 달라진 것은 `filter`가 이제 실제로 읽고 쓰인다는 점과, 신규 상태의 기본값뿐이다. 1단계에서 저장된 기존 데이터는 그대로 유효하다.

현재 위치는 배열 인덱스가 아니라 `currentWordId`로 저장한다. 저장된 ID가 없거나 **현재 필터의 학습 대상 목록**에서 찾을 수 없으면, 그 목록의 첫 번째 카드를 기준으로 삼는다(목록이 비어 있으면 `null`).

## 9. 예외 처리

| 상황 | 동작 |
|---|---|
| 단어 0개 | 카드 대신 "외울 단어를 추가해 보세요" 안내와 "단어 추가" 버튼을 보여주고, "다음"·"암기 완료" 버튼은 비활성화한다. 진척도 영역도 숨긴다. |
| 단어는 있지만 "미완료만" 필터 대상이 0개 *(신규)* | "모든 단어를 외웠어요!" 축하 화면과 "전체 다시 보기" 버튼을 보여주고, "다음"·"암기 완료" 버튼은 비활성화한다. |
| `localStorage` 사용 불가(시크릿 모드·차단 등) | 메모리에서만 동작하고 "이 브라우저에서는 저장되지 않아요" 배너를 표시한다. |
| `localStorage` 저장 용량 초과 *(신규)* | 화면 변경은 유지한 채 "저장 공간이 부족해 저장하지 못했어요" 배너를 표시한다. 이후 저장 시도는 계속한다(F11). |
| 저장 데이터 JSON 파싱 실패·구조 불일치 | 원본 데이터를 `vocabCards.v1.backup` 키로 옮기고 샘플 데이터(필터 기본값 "미완료만")로 다시 시작하며, 안내 메시지를 보여준다. |
| 같은 영단어 중복 추가 시도 *(신규)* | "이미 있는 단어예요. 그래도 추가할까요?" 확인 후 사용자의 선택을 따른다. |

## 10. 비기능 요구사항

- 360px 모바일 폭부터 데스크톱까지 반응형으로 동작한다.
- 모바일에서는 조작 버튼을 화면 하단에 배치하고, 터치 영역은 44×44px 이상으로 하며, "다음" 버튼을 가장 크게 둔다(단, 관리 화면의 "수정"/"삭제" 같은 보조 버튼은 40px 안팎의 작은 버튼으로 둘 수 있다).
- 카드는 `button` 요소로 구현해 Enter/Space로 뒤집을 수 있어야 하며, 앞/뒤 상태를 `aria-pressed` 또는 `aria-live`로 전달한다. 필터 버튼도 `aria-pressed`로 선택 상태를 전달한다.
- 명도 대비 4.5:1 이상을 유지한다(삭제 버튼의 빨간 배경 등 신규 색상 포함).
- 저장/로드, 상태 변경, 렌더링 로직을 함수 단위로 분리하여 다음 단계에서 기능을 추가하기 쉽게 한다.
- **(신규, 설계 메모)** 학습 순환 대상 목록은 `activeQueue`라는 런타임 스냅샷으로 따로 관리한다. 암기 완료 토글은 이 스냅샷을 다시 계산하지 않고, "다음"/필터 변경/단어 추가·삭제 시점에만 다시 계산한다. 이 설계로 F3의 "체크 즉시 사라지지 않음" 요구사항을 별도의 분기 처리 없이 일관되게 만족시킨다.

## 12. 다음 단계로의 연결

- 현재 단어 목록 정렬 기준은 "최신 추가 순" 고정이다. 검색, 다른 정렬 기준(가나다순 등), 카테고리/폴더 분류는 아직 없다.
- 통계(일별 학습량, 연속 학습일 등)나 복습 주기(SRS) 같은 학습 알고리즘은 아직 없다.
- `app.js`는 상태(`appState`), 학습 대상 큐(`activeQueue`), 저장/복원, 렌더링, 동작(flip/next/toggle/filter/add/edit/delete) 함수가 분리되어 있어 3단계 기능을 이 구조 위에 이어 얹을 수 있다.
