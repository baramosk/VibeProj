# 영단어 카드 (3단계)

브라우저에서 바로 쓰는 1인용 영단어 플래시카드 웹앱입니다. 프레임워크나 빌드 도구 없이 순수 HTML/CSS/JavaScript로 만들어졌고, 3단계부터 선택적으로 PWA(오프라인·홈 화면 설치)도 지원합니다.

## 실행 방법

- `index.html`을 더블클릭해서 브라우저로 바로 열면 됩니다.
- 또는 GitHub Pages 등 정적 호스팅에 프로젝트 파일 전체를 올려서 사용할 수 있습니다.
- 별도의 설치나 빌드 과정이 필요 없습니다.
- 정적 호스팅(HTTPS 또는 localhost)으로 열면 서비스 워커가 자동 등록되어 오프라인에서도 열리고, 브라우저의 "홈 화면에 추가"로 설치할 수 있습니다. `index.html`을 파일로 직접 열었을 때(`file://`)는 서비스 워커 등록을 건너뛰므로 오류 없이 평소처럼 동작합니다.

## 키보드 단축키 (학습 화면에서만 동작)

| 키 | 동작 |
|---|---|
| `Space` | 카드 뒤집기 |
| `→` | 다음 카드 |
| `←` | 이전 카드 |
| `M` | 암기 완료 토글 |

입력란(단어 추가, 수정, 일괄 추가)에 포커스가 있을 때는 단축키가 동작하지 않습니다. 화면 하단에 단축키 안내가 작게 표시되며, 모바일 폭(640px 이하)에서는 숨겨집니다.

## 데이터 백업·복원 방법

단어 관리 화면 하단의 "백업" 영역에서:

- **내보내기**: 현재 저장된 모든 단어와 완료 상태를 `vocab-cards-YYYYMMDD.json` 파일로 다운로드합니다. 다른 기기로 옮기거나 수동 백업할 때 사용하세요.
- **가져오기**: 내보낸 JSON 파일을 선택하면 구조를 검증한 뒤 "현재 데이터를 덮어쓸까요?" 확인을 거쳐 전체 데이터를 교체합니다. 파일 구조가 올바르지 않으면 기존 데이터는 그대로 유지되고 오류 안내만 표시됩니다.

이 외에도 단어 목록은 `localStorage`의 `vocabCards.v1` 키에 자동 저장되므로, 같은 브라우저·같은 기기에서는 내보내기 없이도 항상 복원됩니다.

## 파일 구조

```
index.html         화면 구조 (학습 화면 / 단어 관리 화면)
style.css          스타일, 반응형 레이아웃, 카드 플립 애니메이션, 다크 모드
app.js             상태 관리, 저장/복원(+마이그레이션), 렌더링, 이벤트 처리
manifest.json       PWA 매니페스트
service-worker.js   오프라인 캐시용 서비스 워커(간단한 캐시 우선 전략)
icon.svg            PWA/브라우저 탭 아이콘
docs/prd/           단계별 PRD 문서
```

## 기능 목록

### 1단계(MVP)
- **카드 학습**: 카드를 클릭하거나 포커스 후 Enter/Space로 영단어 ↔ 뜻을 뒤집어 볼 수 있습니다. (3D 회전 애니메이션, `prefers-reduced-motion` 설정 시 즉시 전환)
- **다음 카드**: "다음" 버튼으로 순서대로 이동하며, 마지막 카드 다음에는 첫 카드로 순환하고 "한 바퀴를 다 봤어요" 안내가 잠깐 표시됩니다.
- **암기 완료 토글**: 카드별로 암기 완료 상태를 저장하고, 완료된 카드에는 "완료" 배지가 표시됩니다.
- **단어 추가/목록**: 단어 관리 화면에서 영단어·뜻을 추가하고 전체 목록(완료 여부 포함)을 확인할 수 있습니다. 빈 입력, 글자 수 제한(영단어 100자/뜻 200자)을 처리합니다.
- **자동 저장/복원**: `localStorage`에 상태가 즉시 저장되며, 새로고침해도 단어 목록·완료 상태·보던 카드 위치가 그대로 복원됩니다.
- **접근성**: 카드와 버튼은 키보드로 조작 가능하며, 카드의 앞/뒤 상태를 `aria-pressed`와 `aria-live` 영역으로 전달합니다.

### 2단계
- **진척도 표시**: 학습 화면 상단에 "완료 n / 전체 m"과 진행 막대가 표시되고, 암기 완료를 체크/해제할 때마다 즉시 갱신됩니다.
- **학습 범위 필터**: "전체 / 미완료만" 전환 컨트롤을 제공합니다. "미완료만" 모드에서는 암기 완료된 단어가 카드 순환에서 빠지지만, 방금 완료 처리한 카드는 "다음"을 누르기 전까지 화면에 그대로 남아 있습니다.
- **모든 단어 완료 화면**: "미완료만" 모드에서 남은 단어가 없으면 "모든 단어를 외웠어요!" 축하 화면과 "전체 다시 보기" 버튼이 표시됩니다.
- **단어 수정·삭제**: 단어 관리 화면 각 행에서 "수정"(인라인 편집)과 "삭제"(확인 대화상자 후 삭제)를 할 수 있습니다.
- **중복 확인**: 대소문자·공백을 무시하고 이미 있는 영단어를 추가하려 하면 확인을 거칩니다.
- **저장 용량 초과 처리**: `localStorage` 용량 초과(QuotaExceededError) 시 화면 변경은 유지하고 전용 안내만 표시합니다.

### 3단계(신규)
- **이전 버튼**: "다음" 왼쪽에 "이전" 버튼이 추가되어 양방향으로 카드를 넘길 수 있습니다. 첫 카드에서 "이전"을 누르면 마지막 카드로 순환하고, 이동한 카드는 항상 앞면부터 보여줍니다.
- **섞기**: 학습 대상 카드 순서를 무작위로 섞는 "섞기" 버튼과, 원래 추가 순서로 되돌리는 "순서 해제" 버튼을 제공합니다. 섞은 순서는 `AppState.order`(단어 ID 배열)에 저장되어 새로고침 후에도 유지되며, 섞인 상태에서 단어를 추가·삭제해도 순서가 어긋나지 않습니다(새 단어는 끝에 추가, 삭제된 단어는 순서에서 제거).
- **키보드 단축키**: 학습 화면에서 Space(뒤집기)/→(다음)/←(이전)/M(암기 완료)을 지원합니다. 입력란에 포커스가 있으면 동작하지 않고, 화면 하단에 작은 안내 문구가 표시됩니다(모바일에서는 숨김).
- **완료 상태 모두 초기화**: 단어 관리 화면 하단과 "모든 단어를 외웠어요!" 축하 화면의 "완료 초기화" 버튼으로, 확인 후 모든 단어의 암기 완료 상태를 한 번에 되돌릴 수 있습니다.
- **일괄 추가**: 단어 관리 화면에서 여러 줄을 한 번에 붙여넣어 추가할 수 있습니다. 한 줄에 "영단어, 뜻" 또는 "영단어(탭)뜻"(엑셀·구글 시트에서 복사한 두 열) 형식을 지원하며, 뜻에 포함된 쉼표는 그대로 보존됩니다. 빈 줄·형식 오류는 건너뛰고, 중복 단어도 건너뛰며 "n개 추가, m개 건너뜀(중복 k개)" 결과를 보여줍니다.
- **JSON 내보내기·가져오기**: 전체 데이터를 JSON 파일로 내보내거나, 파일을 가져와 구조 검증 후 확인을 거쳐 교체할 수 있습니다(위 "데이터 백업·복원 방법" 참고).
- **다크 모드**: 시스템의 `prefers-color-scheme` 설정에 따라 자동으로 라이트/다크 테마가 전환됩니다. 모든 색상을 CSS 변수로 관리하며, 다크 모드에서도 명도 대비 4.5:1 이상을 유지합니다.
- **여러 탭 동기화**: 같은 브라우저에서 이 앱을 여러 탭에 열어두면, 한 탭에서 바뀐 단어·완료 상태·필터가 `storage` 이벤트를 통해 다른 탭에도 자동 반영됩니다.
- **PWA(선택)**: `manifest.json`과 간단한 서비스 워커로 오프라인 사용과 홈 화면 설치를 지원합니다. `file://`로 열 때는 서비스 워커 등록을 건너뜁니다.
- **데이터 구조 마이그레이션**: 저장 데이터에 `version` 필드를 두어, 1단계 때 저장된 구버전 데이터(`version: 1`, `order` 필드 없음)를 열면 오류 없이 자동으로 현재 구조(`version: 2`, `order: null`)로 변환해 저장합니다.

### 설계 메모

- **데이터 마이그레이션**: `app.js`의 `migrateState()`가 버전별 변환을 단계적으로 처리합니다. `loadState()`는 "최소 공통 구조 검증 → 마이그레이션 → 최종 구조 검증" 순서로 동작하며, 가져오기(JSON import)와 다른 탭 동기화도 같은 파이프라인을 재사용해 일관되게 검증합니다. 마이그레이션이 실제로 일어나면 즉시 다시 저장해 다음 로드부터는 변환 과정 없이 바로 최신 구조를 읽습니다.
- **섞기와 order**: `AppState.order`는 전체 단어 ID의 순서 배열입니다. 카드 순환은 `order` → 필터 적용 순서로 계산되며, `order`에 없는 단어(새로 추가된 단어)는 자동으로 끝에 붙고 삭제된 단어의 ID는 제거되어 항상 `words`와 일관성을 유지합니다.
- **키보드 단축키 vs 버튼 기본 동작 충돌 방지**: 카드(또는 다른 버튼)에 포커스가 있는 상태에서 Space를 누르면 브라우저가 그 버튼을 기본적으로 클릭합니다. 전역 단축키 핸들러는 포커스된 요소가 `button`이면 Space 처리를 건너뛰어, 같은 키 입력으로 카드가 두 번 뒤집히는 문제를 피합니다.
- **여러 탭 동기화**: `window`의 `storage` 이벤트는 변경을 발생시킨 탭에서는 발생하지 않고 다른 탭에만 전달되므로, 별도의 무한 루프 방지 로직 없이 안전하게 상태를 반영합니다.

## 다음 단계에서 이어 작업하기 좋은 지점

- 단어 목록은 "최신 추가 순" 정렬만 지원합니다. 검색, 다른 정렬 기준, 카테고리 분류는 아직 없습니다.
- 다른 탭 동기화는 같은 브라우저 안에서만 동작합니다(기기 간 동기화는 아직 없음).
- `app.js`는 상태(`appState`), 학습 대상 큐(`activeQueue`), 순서(`order`), 저장/복원(+마이그레이션), 렌더링, 동작 함수가 분리되어 있어 이후 기능을 이 구조 위에 이어 얹을 수 있습니다.
