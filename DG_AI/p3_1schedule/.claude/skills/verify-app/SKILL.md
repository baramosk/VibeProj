# 앱 동작 확인

실제 `schedules.json`을 보호하기 위해 항상 임시 폴더 복사본에서 실행한다.

1. 임시 폴더를 만들고 `main.py`, `schedule_manager.py`, `schedules.json`을 복사한다. (스크래치패드 디렉터리가 있으면 그 안에 만든다.)
2. 아래 기본 시나리오를 표준 입력으로 넣어 실행한다. 한글 출력을 위해 `PYTHONIOENCODING=utf-8`을 설정한다.

   ```bash
   printf '1\n2026-11-02\n09:00\n회의\n주간 회의\n1\n2026-11-01\nbad\nx\n\n1\n2026-11-01\n14:30\n병원\n\n2\n3\n9\n3\n1\n4\n5\n2\n0\n' \
     | PYTHONIOENCODING=utf-8 C:/Users/great/anaconda3/envs/py311/python.exe "<임시폴더>/main.py"
   ```

   이 시나리오는 정상 추가, 잘못된 시간 입력, 두 번째 추가(날짜순 정렬 확인), 목록, 없는 번호 삭제, 정상 삭제, 저장, 불러오기, 목록, 종료를 순서대로 실행한다.
3. 이번에 바꾼 기능이 있으면 그 기능을 검증하는 입력을 시나리오에 추가한다. 메뉴 번호나 입력 순서가 바뀌었다면 시나리오도 맞게 고친다.
4. 출력과 임시 폴더의 `schedules.json` 내용을 확인한다.
   - 추가·삭제 안내 문구가 나오는지
   - 잘못된 입력에 오류 메시지가 나오고 프로그램이 멈추지 않는지
   - 목록이 날짜·시간 순인지
   - 저장 파일이 기대한 내용인지 (한글이 깨지지 않는지)
5. 결과를 사용자에게 한국어로 짧게 보고한다. 실패한 항목은 실제 출력과 함께 알린다. 끝나면 임시 폴더를 지운다.
